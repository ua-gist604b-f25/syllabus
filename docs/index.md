**Fall 2025** | **University of Arizona** | **3 Credits**

## 🎓 Welcome to Open Source GIS!

This course introduces open source geospatial technologies and workflows for master's-level students. You'll learn professional version control, desktop GIS with QGIS, Python spatial analysis, spatial databases with PostGIS, web mapping, and AI-enhanced GIS workflows.

**Course Dates:** October 16 - December 10, 2025 (7 weeks, intensive format)  
**Format:** Hybrid (online + in-person sessions)

## 🎯 Learning Outcomes

By the end of this course, you will be able to:

1. **Apply professional version control workflows** using Git and GitHub for spatial data projects
2. **Perform spatial analysis and cartography** using QGIS and open source desktop GIS tools
3. **Develop Python-based GIS applications** using containerized development environments
4. **Design and query spatial databases** using PostGIS and SQL
5. **Build full-stack web mapping applications** with modern JavaScript libraries
6. **Integrate AI technologies** into geospatial workflows for enhanced analysis
7. **Deploy and document professional GIS portfolios** demonstrating technical competencies
