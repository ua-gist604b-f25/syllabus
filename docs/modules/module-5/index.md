## 🎯 Module Overview (Preview)

Module 5 introduces **web mapping and full-stack GIS applications**, teaching you to build interactive maps accessible to broad audiences. You'll learn to:

- Build interactive web maps using Leaflet and MapLibre
- Integrate spatial data from APIs and tile services
- Deploy and configure GeoServer for map publishing
- Orchestrate multi-service web GIS applications with Docker Compose
- Implement full-stack web mapping solutions
- Deploy web GIS applications for public access

**Why This Matters:** Web mapping democratizes spatial data, making GIS accessible beyond desktop software users. These skills are essential for public-facing GIS work, data journalism, civic tech, and modern GIS application development.
