## 🎯 Learning Objectives (Planned)

Students completing Module 5 will be able to:
1. Build interactive web maps using Leaflet and MapLibre
2. Integrate spatial data from APIs and tile services
3. Deploy and configure GeoServer for map publishing
4. Orchestrate multi-service web GIS applications with Docker Compose
5. Implement full-stack web mapping solutions
6. Deploy web GIS applications for public access

---

## 🌍 Module Theme

**Web mapping applications, service orchestration, and full-stack deployment**

This module teaches modern web GIS development, enabling students to create interactive mapping applications accessible to broad audiences—a critical skill for public-facing GIS work.
