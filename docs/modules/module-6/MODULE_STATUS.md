## 🎯 Learning Objectives (Planned)

Students completing Module 6 will be able to:
1. Deploy and interact with local LLMs (Ollama) in containerized environments
2. Use Model Context Protocol (MCP) for GIS-specific AI interactions
3. Apply prompt engineering techniques for spatial analysis tasks
4. Critically evaluate ethical implications of AI in GIS
5. Integrate AI tools into professional GIS workflows
6. Assess when AI enhancement adds value vs. introduces risk
