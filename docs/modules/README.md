- **index.md** - Module overview, learning objectives, assignments, activities

## 📊 Module Status Legend

- **✅ Released** - All materials available, students can start work
- **📝 Draft** - Materials under development, not yet available to students
- **🚧 In Progress** - Partial materials available
- **⏳ Pending** - Not yet started

---

## 🎯 Module Progression

Modules build on each other systematically:

1. **Module 1** - Foundation in open source principles and version control
2. **Module 2** - Desktop GIS skills with QGIS
3. **Module 3** - Python programming for spatial analysis
4. **Module 4** - Spatial databases and SQL
5. **Module 5** - Web mapping and full-stack applications
6. **Module 6** - AI integration in GIS workflows
7. **Module 7** - Portfolio synthesis and career preparation

**Collaborative Project** runs throughout, integrating skills from multiple modules.

## 💡 Using This Directory

### For Students
- Navigate to individual module pages for complete information
- Check MODULE_STATUS.md files to see development progress
- Modules release weekly - check back for new content

### For Instructors
- Each module directory can contain subdirectories for:
  - `assignments/` - Assignment markdown files (optional)
  - `activities/` - Activity instructions (optional)
  - `resources/` - Additional materials (optional)
- Status files track completion and help manage staged releases
