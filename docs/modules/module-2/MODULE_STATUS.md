## 🎯 Learning Objectives

Students completing Module 2 will be able to:
1. Navigate the QGIS interface and manage spatial data layers
2. Perform coordinate reference system transformations
3. Execute spatial analysis operations (buffers, intersections, joins)
4. Create professional cartographic outputs with proper symbology
5. Export maps and data for client deliverables

---

## 🗺️ Module Theme

**Desktop GIS fundamentals and spatial analysis with QGIS**

This module transitions students from proprietary ESRI tools (ArcGIS) to open source QGIS, building confidence with desktop GIS workflows that transfer across platforms.
