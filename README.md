## 🎓 About This Course

**GIST 604B** introduces open source geospatial technologies for master's-level students. Topics include:
- Professional version control with Git and GitHub
- Desktop GIS with QGIS
- Python spatial analysis with containerized workflows
- Spatial databases with PostGIS
- Web mapping applications
- AI-enhanced GIS workflows
- Professional portfolio development

**Format:** Hybrid (online + in-person)  
**Duration:** October 16 - December 10, 2025 (7 weeks, intensive)  
**Meetings:** Monday, Tuesday, Thursday 4:30-6:30 PM MST
